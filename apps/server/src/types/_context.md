# apps/server/src/types 디렉토리

이 디렉토리는 YouTube 동영상 공유 플레이어 애플리케이션의 서버에서 사용하는 타입 정의를 포함하고 있습니다.

## 주요 파일

- `index.ts`: 서버 내부에서 사용하는 주요 타입 정의
- `shared.d.ts`: 클라이언트와 서버 간에 공유되는 타입 정의

## 주요 기능

### 주요 타입 정의 (index.ts)

다음과 같은 주요 타입을 정의합니다:

- `RoomState`: 방의 상태 정보 (사용자, 설정, 비디오 정보 등)
- `UserState`: 사용자 정보 (ID, 닉네임, 연결 상태 등)
- `PlayerState`: 플레이어 상태 정보 (재생 상태, 현재 시간 등)
- `PlaylistItem`: 재생목록 항목 정보
- `ChatMessage`: 채팅 메시지 구조
- `EventLog`: 이벤트 로깅 정보
- `RoomSettings`: 방 설정 정보 (비밀번호, 권한 등)

### 공유 타입 정의 (shared.d.ts)

클라이언트와 서버 간 통신에 사용되는 타입을 정의합니다:

- 소켓 이벤트 페이로드 타입
- API 응답 타입
- 클라이언트-서버 간 데이터 교환 인터페이스
- 유틸리티 타입 및 열거형
