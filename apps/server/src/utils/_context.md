# apps/server/src/utils 디렉토리

이 디렉토리는 YouTube 동영상 공유 플레이어 애플리케이션의 서버에서 사용하는 유틸리티 함수를 포함하고 있습니다.

## 주요 파일

- `helpers.ts`: 다양한 유틸리티 헬퍼 함수
- `logger.ts`: 로깅 유틸리티
- `nameGenerator.ts`: 임의 닉네임 생성 유틸리티

## 주요 기능

### 헬퍼 함수 (helpers.ts)

다음과 같은 유틸리티 함수를 제공합니다:

- 고유 ID 생성
- 시간 포맷팅
- 데이터 변환
- 문자열 처리
- 객체 조작

### 로깅 시스템 (logger.ts)

서버 로깅을 위한 기능을 제공합니다:

- 다양한 로그 레벨 지원 (debug, info, warn, error)
- 구조화된 로깅
- 환경별 로그 레벨 설정
- 컬러 지원 (개발 환경)

### 닉네임 생성기 (nameGenerator.ts)

임의의 닉네임을 생성하는 기능을 제공합니다:

- 형용사-명사 조합의 임의 닉네임 생성
- 한국어/영어 닉네임 지원
- 중복 방지 메커니즘
