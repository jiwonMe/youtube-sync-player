# apps/server/src 디렉토리

이 디렉토리는 YouTube 동영상 공유 플레이어 애플리케이션의 서버 소스 코드를 포함하고 있습니다.

## 주요 파일 및 디렉토리

- `server.ts`: 메인 서버 설정 및 Socket.io 이벤트 라우팅
- `config/`: 서버 설정 및 환경 변수 관리
- `handlers/`: HTTP 및 소켓 이벤트 핸들러
- `models/`: 데이터 모델 (향후 확장용)
- `services/`: 데이터 관리 서비스 (roomStore 등)
- `types/`: 타입 정의
- `utils/`: 유틸리티 함수

## 서버 구조 개요

### 서버 초기화 및 설정 (server.ts)

`server.ts`는 서버의 진입점으로, 다음과 같은 기능을 담당합니다:

- Express 서버 및 Socket.io 설정
- 미들웨어 설정 (CORS, 로깅 등)
- HTTP 라우트 등록
- 소켓 이벤트 리스너 등록
- 이벤트 핸들러 바인딩

### 모듈식 아키텍처

서버는 다음과 같은 모듈화된 구조로 설계되었습니다:

1. **설정 레이어** (`config/`): 환경 변수 및 앱 설정 관리
2. **핸들러 레이어** (`handlers/`): HTTP 및 소켓 이벤트 처리 로직
3. **서비스 레이어** (`services/`): 비즈니스 로직 및 데이터 관리
4. **모델 레이어** (`models/`): 데이터 모델 정의 (향후 확장용)
5. **유틸리티 레이어** (`utils/`): 공통 유틸리티 함수
6. **타입 레이어** (`types/`): 전체 애플리케이션에서 사용하는 타입 정의

### 주요 워크플로우

1. 클라이언트가 HTTP 요청 또는 Socket.io 이벤트 발생
2. `server.ts`에서 해당 이벤트를 적절한 핸들러로 라우팅
3. 핸들러는 서비스 레이어를 통해 데이터 처리
4. 서비스 레이어는 필요에 따라 데이터 저장소에 접근
5. 결과는 핸들러를 통해 클라이언트에 반환

### Supabase 통합

서버는 2024년 3월 19일부터 메모리 기반 저장소에서 Supabase 데이터베이스로 마이그레이션되었습니다. 대부분의 데이터 영속성은 이제 `roomSupabaseStore.ts` 서비스를 통해 Supabase에서 관리됩니다.
