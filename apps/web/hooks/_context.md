# apps/web/hooks 디렉토리

이 디렉토리는 애플리케이션에서 사용되는 React 커스텀 훅들을 포함하고 있습니다.

## 주요 파일

- `use-mobile.tsx`: 모바일 기기 감지를 위한 커스텀 훅
- `use-player-sync.ts`: YouTube 플레이어 동기화를 위한 커스텀 훅
- `use-toast.ts`: 토스트 알림 표시를 위한 커스텀 훅

## 주요 훅 설명

### use-mobile.tsx

이 훅은 현재 기기가 모바일인지 여부를 감지합니다. 반응형 UI를 구현하는 데 사용되며, 화면 크기에 따라 다른 레이아웃이나 기능을 제공할 때 유용합니다.

```tsx
const isMobile = useMobile();

// 사용 예시
return (
  <div>
    {isMobile ? (
      <MobileLayout />
    ) : (
      <DesktopLayout />
    )}
  </div>
);
```

### use-player-sync.ts

이 훅은 YouTube 플레이어의 상태를 여러 클라이언트 간에 동기화하는 데 사용됩니다. 소켓 통신을 통해 재생 상태, 현재 시간, 비디오 변경 등의 이벤트를 처리합니다.

주요 기능:
- 비디오 재생/일시정지 동기화
- 재생 시간 동기화
- 비디오 변경 이벤트 처리
- 자동 재생 설정 관리

### use-toast.ts

이 훅은 애플리케이션 전체에서 일관된 방식으로 토스트 알림을 표시하는 데 사용됩니다. 성공, 오류, 정보 등 다양한 유형의 알림을 지원합니다.

```tsx
const { toast } = useToast();

// 사용 예시
toast({
  title: "성공",
  description: "작업이 성공적으로 완료되었습니다.",
  variant: "success",
});
```

## 훅 설계 원칙

- **재사용성**: 여러 컴포넌트에서 공통 로직을 재사용할 수 있도록 설계
- **관심사 분리**: UI와 비즈니스 로직을 분리하여 코드 유지보수성 향상
- **타입 안전성**: TypeScript를 활용한 타입 안전한 인터페이스 제공
- **성능 최적화**: 불필요한 리렌더링을 방지하기 위한 메모이제이션 활용
