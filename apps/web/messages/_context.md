# apps/web/messages 디렉토리

이 디렉토리는 애플리케이션의 다국어 지원을 위한 메시지 파일들을 포함하고 있습니다.

## 주요 하위 디렉토리

- `en/`: 영어 메시지 파일
- `ko/`: 한국어 메시지 파일

## 다국어 지원 구조

이 디렉토리는 [next-intl](https://next-intl-docs.vercel.app/) 또는 유사한 국제화 라이브러리를 사용하여 애플리케이션의 다국어 지원을 구현합니다. 각 언어별 하위 디렉토리에는 해당 언어로 번역된 메시지가 포함되어 있습니다.

### 메시지 구조

각 언어 디렉토리에는 다음과 같은 메시지 파일들이 포함될 수 있습니다:

- `common.json`: 공통 메시지 (버튼, 레이블, 오류 메시지 등)
- `home.json`: 홈페이지 관련 메시지
- `room.json`: 방 페이지 관련 메시지
- `auth.json`: 인증 관련 메시지
- 기타 페이지 또는 기능별 메시지 파일

### 사용 방법

애플리케이션에서는 다음과 같이 메시지를 사용할 수 있습니다:

```tsx
import { useTranslations } from 'next-intl';

function MyComponent() {
  const t = useTranslations('common');
  
  return (
    <div>
      <h1>{t('title')}</h1>
      <p>{t('description')}</p>
      <button>{t('buttons.submit')}</button>
    </div>
  );
}
```

## 다국어 지원 원칙

- **일관성**: 모든 언어에서 동일한 키 구조 유지
- **완전성**: 모든 텍스트는 번역 가능하도록 메시지 파일에 포함
- **컨텍스트 제공**: 번역자를 위한 주석 및 컨텍스트 정보 제공
- **동적 콘텐츠**: 변수 및 복수형 처리 지원

## 언어 추가 방법

새로운 언어를 추가하려면:

1. 새 언어 코드로 하위 디렉토리 생성 (예: `fr/` for French)
2. 기존 언어 파일을 복사하여 새 언어로 번역
3. 애플리케이션의 언어 선택기에 새 언어 추가
4. 필요한 경우 언어별 날짜, 숫자 형식 등의 추가 설정 구성
