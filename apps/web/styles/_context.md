# apps/web/styles 디렉토리

이 디렉토리는 애플리케이션의 전역 스타일 및 CSS 관련 파일들을 포함하고 있습니다.

## 주요 파일

- `globals.css`: 애플리케이션 전역 스타일 정의

## 주요 파일 설명

### globals.css

이 파일은 애플리케이션 전체에 적용되는 전역 스타일을 정의합니다. Tailwind CSS의 기본 스타일과 사용자 정의 스타일을 포함합니다.

주요 내용:
- Tailwind CSS 기본 지시문 (`@tailwind base`, `@tailwind components`, `@tailwind utilities`)
- 글꼴 설정
- 색상 변수
- 기본 요소 스타일 (body, headings, links 등)
- 애니메이션 정의
- 유틸리티 클래스

## 스타일링 접근 방식

이 프로젝트는 주로 Tailwind CSS를 사용하여 스타일링을 구현합니다. 이는 다음과 같은 특징을 가집니다:

- **유틸리티 우선 접근법**: 사전 정의된 유틸리티 클래스를 조합하여 스타일 적용
- **반응형 디자인**: 다양한 화면 크기에 대응하는 반응형 클래스 사용
- **테마 지원**: 다크 모드/라이트 모드 지원을 위한 테마 변수 사용
- **컴포넌트 확장**: `@apply` 지시문을 사용한 컴포넌트 스타일 확장

## CSS 모듈 및 CSS-in-JS

이 프로젝트는 주로 Tailwind CSS를 사용하지만, 필요에 따라 다음과 같은 접근 방식도 사용할 수 있습니다:

- **CSS 모듈**: 컴포넌트별 스코프가 지정된 CSS를 위한 `.module.css` 파일
- **CSS-in-JS**: 스타일드 컴포넌트나 이모션과 같은 라이브러리를 사용한 인라인 스타일링
- **SCSS/SASS**: 필요한 경우 전처리기를 사용한 고급 스타일링

## 스타일 가이드라인

- **일관성**: 일관된 색상, 간격, 타이포그래피 사용
- **접근성**: 충분한 대비와 접근 가능한 디자인 유지
- **성능**: 불필요한 CSS 최소화 및 최적화
- **유지보수성**: 명확하고 구조화된 스타일 코드 작성
