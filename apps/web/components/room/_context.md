# apps/web/components/room 디렉토리

이 디렉토리는 YouTube 동영상 공유 방과 관련된 컴포넌트들을 포함하고 있습니다.

## 주요 파일

- `add-video-dialog.tsx`: 비디오 추가 다이얼로그 컴포넌트
- `chat-panel.tsx`: 채팅 패널 컴포넌트
- `password-dialog.tsx`: 비밀번호 입력 다이얼로그 컴포넌트
- `playlist-panel.tsx`: 플레이리스트 패널 컴포넌트
- `upcoming-playlist.tsx`: 예정된 재생 목록 컴포넌트
- `users-panel.tsx`: 사용자 목록 패널 컴포넌트
- `video-controls.tsx`: 비디오 제어 컴포넌트

## 주요 컴포넌트 설명

### add-video-dialog.tsx

YouTube 비디오 URL 또는 ID를 입력하여 플레이리스트에 비디오를 추가할 수 있는 다이얼로그 컴포넌트입니다. 비디오 정보를 가져와 플레이리스트에 추가하는 기능을 제공합니다.

### chat-panel.tsx

실시간 채팅 기능을 제공하는 패널 컴포넌트입니다. 메시지 표시, 입력, 전송 기능을 포함하며, 소켓을 통해 실시간으로 다른 사용자와 메시지를 주고받을 수 있습니다.

### password-dialog.tsx

비밀번호로 보호된 방에 입장할 때 비밀번호를 입력하는 다이얼로그 컴포넌트입니다. 비밀번호 검증 및 오류 처리 기능을 포함합니다.

### playlist-panel.tsx

현재 방의 플레이리스트를 관리하는 패널 컴포넌트입니다. 비디오 목록 표시, 재생 순서 변경, 비디오 제거 등의 기능을 제공합니다.

### upcoming-playlist.tsx

다음에 재생될 비디오 목록을 표시하는 컴포넌트입니다. 현재 재생 중인 비디오 다음에 예정된 비디오들을 보여줍니다.

### users-panel.tsx

현재 방에 참여 중인 사용자 목록을 표시하는 패널 컴포넌트입니다. 호스트 표시, 사용자 프로필 이미지, 이름 등을 보여줍니다.

### video-controls.tsx

비디오 재생 제어 기능을 제공하는 컴포넌트입니다. 재생/일시정지, 볼륨 조절, 시간 이동, 전체 화면 등의 컨트롤을 포함합니다.

## 상호작용 패턴

- **소켓 통신**: 모든 컴포넌트는 소켓을 통해 서버 및 다른 클라이언트와 실시간 통신
- **상태 동기화**: 비디오 재생 상태, 채팅 메시지, 사용자 목록 등을 실시간으로 동기화
- **권한 관리**: 호스트와 일반 사용자의 권한 차이 처리
- **반응형 UI**: 다양한 화면 크기에 대응하는 레이아웃
