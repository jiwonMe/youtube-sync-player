# packages/shared 디렉토리

이 디렉토리는 모노레포 내에서 여러 애플리케이션 간에 공유되는 코드를 포함하고 있습니다.

## 주요 파일

- `package.json`: 패키지 의존성 및 스크립트 정의
- `tsconfig.json`: TypeScript 컴파일러 설정

## 주요 하위 디렉토리

- `src/`: 소스 코드
  - `index.ts`: 패키지의 진입점
  - `types.ts`: 공유 타입 정의

## 주요 내용 설명

### types.ts

이 파일은 여러 애플리케이션에서 공유되는 타입 정의를 포함하고 있습니다. 주로 서버와 클라이언트 간에 일관된 데이터 구조를 유지하기 위해 사용됩니다.

주요 타입:
- 방 관련 타입 (RoomUser, ChatMessage, VideoItem 등)
- 소켓 이벤트 관련 타입
- API 요청/응답 타입
- 기타 공통 타입

### index.ts

이 파일은 패키지의 진입점으로, 외부에 노출할 모든 타입과 함수를 내보냅니다.

```typescript
// 모든 타입 내보내기
export * from './types';

// 필요한 경우 유틸리티 함수 내보내기
export * from './utils';
```

## 패키지 용도

이 패키지는 다음과 같은 목적으로 사용됩니다:

- **타입 공유**: 서버와 클라이언트 간에 일관된 타입 정의 제공
- **코드 중복 방지**: 여러 애플리케이션에서 공통으로 사용되는 코드 중복 방지
- **일관성 유지**: 모든 애플리케이션에서 동일한 데이터 구조 및 로직 사용 보장
- **유지보수 용이성**: 공통 코드를 한 곳에서 관리하여 유지보수 용이

## 패키지 사용 방법

이 패키지는 모노레포 내의 다른 애플리케이션에서 다음과 같이 사용할 수 있습니다:

```json
// 다른 애플리케이션의 package.json
{
  "dependencies": {
    "shared": "*"
  }
}
```

```typescript
// 다른 애플리케이션의 코드에서 사용
import { RoomUser, ChatMessage, VideoItem } from "shared";

const user: RoomUser = {
  id: "user-123",
  name: "John Doe",
  image: "https://example.com/avatar.jpg"
};
```

## 패키지 확장 가이드라인

이 패키지를 확장할 때는 다음 가이드라인을 따르는 것이 좋습니다:

1. 여러 애플리케이션에서 공통으로 사용되는 코드만 추가
2. 명확한 타입 정의와 주석 제공
3. 패키지 크기를 최소화하여 빌드 시간 및 번들 크기 최적화
4. 하위 호환성을 유지하여 기존 애플리케이션에 영향 최소화
5. 필요한 경우 단위 테스트 작성
