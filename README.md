# YouTube Sync Player

A multiplayer synchronized YouTube player with shared playlists. Watch videos with friends in perfect sync, no matter where they are.

## Features

- Synchronized YouTube video playback
- Shared playlists
- Real-time chat
- User presence
- Google authentication for YouTube playlists

## Development

### Prerequisites

- Node.js 16+
- npm or yarn
- A Google OAuth client ID and secret for authentication
